# 👑 КТО ХОЧЕТ СТАТЬ МИЛЛИОНЕРОМ? — веб-игра для класса

Интеллектуальная игра по истории (формат телешоу «Кто хочет стать миллионером?»),
адаптированная под **командный** формат с ведущим. Один человек (ведущий/учитель)
управляет сайтом с одного устройства, proyectando экран на весь класс.

Готовый проект на **ASP.NET Core 8** (Minimal API + vanilla JS, без сборки фронтенда).
Всё содержимое (стили, звуки, анимации) — локальное, интернет не нужен.

---

## ✨ Возможности

- **Любое число команд** — добавляются за секунды на стартовом экране.
- **Табло вопросов**: вопросы из `quiz.json` распределены по стоимости
  (10 × 1 балл, 10 × 2 балла, 10 × 3 балла + 9 резервных). Сыгранные вопросы
  гаснут и больше никому не достаются.
- **Рулетка**: команда выбирает стоимость — лента с номерами вопросов
  раскручивается и случайно останавливается на одном из оставшихся вопросов категории.
  Иногда вместо вопроса выпадает модификатор счёта: **+1, +2, −1 или −2 балла**
  (вопрос при этом не расходуется).
- **Таймер ответа**: на каждый вопрос даётся **30 секунд** (настраивается).
  Если время вышло — правильный ответ показывается, очки не начисляются.
- **Полный цикл ответа**: suspense-мигание выбранного варианта → зелёная/красная
  анимация, конфетти или тряска экрана, всплывающие «+N / −N», пояснение к вопросу.
- **Очки**: верно → **+стоимость вопроса**, неверно → **−стоимость**.
- **Шесть подсказок/модификаторов на команду**:
  - **50:50** — сайт убирает два неверных варианта;
  - **📞 Звонок учителю** — таймер, пока учитель подсказывает;
  - **👥 Помощь зала** — таймер, пока другие команды советуют ответ;
  - **🔄 Передача вопроса** — отдать текущий вопрос другой команде
    (не более **одного раза за ход** и одного раза за игру для команды);
  - **🛡 Страховка** — ошибка на этом вопросе не отнимает очки (один раз за игру);
  - **✖2 Удвоение** — очки вопроса удваиваются в обе стороны (один раз за игру;
    не совмещается со страховкой).
- **Финал**: кнопка «🏁 Подвести итоги» в любой момент **или** автоматически,
  когда вопросы закончились. Пьедестал, таблица, победитель (ничья поддерживается).
- **Сохранение состояния**: перезапуск контейнера/сервера не убивает игру —
  счёт, сыгранные вопросы и даже открытый ход восстанавливаются.
- Звуки (фанфары, барабанная дробь suspense, колокол таймера) синтезируются
  браузером — никаких аудиофайлов. Кнопка 🔊/🔇 в шапке.

## 🚀 Быстрый старт (Docker + env) — ваш VPS

Нужны только установленные **Docker** и **Docker Compose** (в новых Docker входит
в состав плагина `docker compose`).

```bash
# 1. Скопируйте папку проекта на сервер (git clone / scp / архив)
scp -r millionaire-quiz user@ваш-сервер:~/

# 2. Настройте окружение
cd millionaire-quiz
cp .env.example .env
nano .env          # например, PORT=8080, PHONE_SECONDS=90

# 3. Соберите и запустите
docker compose up -d --build

# 4. Проверьте
curl http://localhost:8080/healthz   # → ok
```

Откройте в браузере `http://IP-ВАШЕГО-СЕРВЕРА:8080` — и играйте.

### Переменные окружения (.env)

| Переменная          | По умолчанию | Назначение                                              |
|---------------------|--------------|---------------------------------------------------------|
| `PORT`              | `8080`       | Порт на хосте (внутри контейнера всегда 8080)           |
| `GAME_TITLE`        | из quiz.json | Переопределить заголовок игры                           |
| `GAME_SUBTITLE`     | из quiz.json | Переопределить подзаголовок                             |
| `GAME_THEME`        | из quiz.json | Переопределить строку темы                              |
| `PHONE_SECONDS`     | `60`         | Длительность таймера «Звонок учителю», сек              |
| `AUDIENCE_SECONDS`  | `60`         | Длительность таймера «Помощь зала», сек                 |
| `ANSWER_SECONDS`    | `30`         | Время на ответ по вопросу, сек                          |
| `BACKUP_POINTS`     | `0`          | Очки за резервные вопросы (0 = не влияют на счёт)       |

Изменения `.env` применяются командой `docker compose up -d` (пересоздание контейнера).

### Свои вопросы

Файл вопросов лежит в `Data/quiz.json` и примонтирован в контейнер.
Отредактируйте его на сервере и выполните:

```bash
docker compose restart
```

Формат файла — как в поставленном примере: массивы `questions` и
`backup_questions` с полями `number`, `points`, `question`, `options`
(буквы A–D, у одного варианта `"correct": true`), `correct_answer`, `explanation`.
Категории на табло строятся автоматически по полю `points`.

### HTTPS / домен (по желанию)

Игра — обычный HTTP-сайт. Для HTTPS поставьте перед ней любой reverse-proxy,
например **Caddy** (авто-SSL):

```caddyfile
quiz.ваш-домен.ru {
    reverse_proxy localhost:8080
}
```

или nginx + certbot по стандартной схеме. Внутри сети/класса можно играть и по HTTP.

## 🎮 Как ведёт игру ведущий

1. **Стартовый экран** — добавьте команды (Enter или «Добавить»), «🎮 Начать игру».
2. Клик по **карточке команды** слева — чей ход (карточка загорается золотом, метка «▶ ХОД»).
3. Клик по **колонке стоимости** (1 / 2 / 3 балла или Резерв) — крутится рулетка.
   Обычно выпадает случайный несыгранный вопрос категории, но может выпасть
   и модификатор счёта **+1 / +2 / −1 / −2** — он сразу меняет счёт команды.
4. На ответ даётся **30 секунд** (таймер над вопросом). Если время вышло —
   ведущий видит правильный ответ, а очки не меняются. Иначе команда совещается
   и называет букву — ведущий кликает по варианту:
   - мигание «suspense» (~2,5 с) → вердикт: **зелёный + конфетти + «+N»** или
     **красный + тряска + «−N»**, ниже — правильный ответ и комментарий;
   - «Следующий ход →» закрывает ход.
5. Подсказки и модификаторы текущего хода — кнопки под вариантами:
   **½ 50:50**, **📞 Звонок учителю** (таймер), **👥 Помощь зала** (таймер),
   **🔄 Передача вопроса** (выбор другой команды; один раз за ход),
   **🛡 Страховка**, **✖2 Удвоение**. На таймере подсказки есть «Пауза»
   и «Завершить» досрочно; таймер ответа на это время приостанавливается.
6. «🏳️ Сдать ход» — команда отказывается отвечать: вопрос сгорает, очки не меняются.
7. **«🏁 Подвести итоги»** — завершить игру и показать пьедестал.
   Если вопросы кончились раньше — игра подведёт итоги сама.
8. После финала: «🔄 Новая игра (те же команды)» или «🧹 Полный сброс».

Подсказки, счёт и сыгранные вопросы видны на карточках команд и ячейках табло
(✔ верно, ✘ неверно, – сдано).

## 🧑‍💻 Локальная разработка без Docker

Нужен .NET SDK 8.0:

```bash
cd millionaire-quiz
dotnet run            # http://localhost:5000 (или см. вывод консоли)
# или явно:
ASPNETCORE_URLS=http://localhost:5099 dotnet run
```

Состояние игры сохраняется в `state/gamestate.json` рядом с проектом
(удалите файл или нажмите «Полный сброс», чтобы обнулить).

## 🔌 REST API (если захочется интеграций)

`GET /api/config`, `GET /api/state`, `POST /api/teams`, `DELETE /api/teams/{id}`,
`POST /api/start`, `POST /api/active-team`, `POST /api/spin`, `POST /api/lifeline`,
`POST /api/answer`, `POST /api/pass`, `POST /api/close-turn`, `POST /api/finish`,
`POST /api/reset`. Правильный ответ **не передаётся клиенту** до момента ответа —
подглядеть его из devtools во время раунда нельзя.

## ❓ Troubleshooting

- **Порт занят** — поменяйте `PORT` в `.env`.
- **Игра «застряла» на старой партии** — «🧹 Полный сброс» на финальном экране
  или `docker compose down -v` (удалит том с состоянием).
- **Поменяли quiz.json, а на сайте старое** — `docker compose restart`.
- **Контейнер перезапустился посреди урока** — ничего не потеряется: состояние
  восстанавливается из тома `quiz-state`.
